## 🚀 How to Run Locally

### Option 1: Directly in Browser
Double-click `index.html` to open it in your default browser (Chrome, Edge, Firefox, Brave, Safari).

### Option 2: Using Python (Local Dev Server)
Run the following in your terminal from this folder:
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000).

## 🌐 Free Hosting & Deployment Guide

This portfolio has zero build steps and zero dependencies, making it deployable anywhere in under 60 seconds:

1. **GitHub Pages**:
   - Push this repository to GitHub.
   - Go to **Settings > Pages > Branch: main / root**.
   - Your site will be live at `https://<username>.github.io/<repo-name>/`.
2. **Vercel / Netlify**:
   - Drag and drop this folder into [vercel.com](https://vercel.com) or [netlify.com](https://netlify.com).
   - Instant deployment with custom domain support.
